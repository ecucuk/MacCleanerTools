# Updater Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Updater tool. It lists outdated Homebrew, MacPorts, App Store and Sparkle software, and it upgrades the selected Homebrew items.

**Architecture:** A C++20 core module (`updater`) holds the parsers, the version compare and the check/upgrade flow. All external commands (brew, port, mdls, curl) go through one injected `RunFn`. A platform file supplies the real environment (Info.plist reader, locale region, tool paths). The CLI `updates` subcommand and an ObjC model + view controller use the core.

**Tech Stack:** C++20, `posix_spawn`, CoreFoundation/Foundation (platform file only), AppKit/ObjC++, CMake + Ninja.

**Spec:** `docs/superpowers/specs/2026-10-31-updater-design.md`

## Global Constraints

- Build: `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo && cmake --build build`. Test: `ctest --test-dir build --output-on-failure`. Check the build output before you trust `ctest`.
- Tests: `tests/maccleaner_tests.cpp`, `CHECK` / `CHECK_EQ`, register each test in `main()`.
- No new third-party dependency. No shell (`/bin/sh -c`) anywhere. No `sudo`.
- Tool paths: brew `/opt/homebrew/bin/brew` then `/usr/local/bin/brew`; port `/opt/local/bin/port`; `/usr/bin/curl`; `/usr/bin/mdls`; `/usr/bin/env`.
- curl argv: `/usr/bin/curl -fsSL --proto =https --max-time 10 --max-filesize 5M <url>`.
- Timeouts (s): `brew update` 120, other checks 60, curl 10 (runner timeout 15), `brew upgrade` 1800.
- Upgrade env: `HOMEBREW_NO_AUTO_UPDATE=1`, `NONINTERACTIVE=1`, passed as `/usr/bin/env K=V ... brew upgrade [--cask] <name>`.
- No network on app launch. Network only on "Check" / `mac_cleaner updates`.
- Commits: Conventional Commits, no `Co-Authored-By` trailer.

## Review Focus

1. brew prints a warning line before the JSON (for example after `brew update`): the parser must find the JSON, not fail. Test: `testBrewOutdatedSkipsLeadingNoise` (Task 2).
2. An app with `SUFeedURL` but no `CFBundleVersion`: it must be skipped, not listed as outdated against `""`. Test: `testCheckSkipsSparkleWithoutBundleVersion` (Task 3).
3. A command that hangs (curl on a dead host, brew lock): the runner must return after its timeout. Test: `testRunCommandTimesOut` runs `/bin/sleep 5` with timeout 1 and expects exit `-1` in < 3 s (Task 3).
4. A failed source (brew exit 1, curl 404) must not hide the other sources: the error goes into that `SourceStatus`, other items stay. Test: `testCheckReportsBrewFailureKeepsOthers` (Task 3).
5. An App Store version equal to the installed one but written as `1.0` vs `1.0.0`: not outdated. Covered by `compareVersions("1.0", "1.0.0") == 0` (Task 2).

**Interfaces:**
- Consumes: Task 2 parsers and `OutdatedItem`.
- Produces:
```cpp
struct CommandResult { int exitCode = 0; std::string output; }; // exitCode -1 = timeout or spawn failure
using RunFn = std::function<CommandResult(const std::vector<std::string>& argv, int timeoutSeconds)>;
CommandResult runCommand(const std::vector<std::string>& argv, int timeoutSeconds);

struct BundleInfo { std::string shortVersion, bundleVersion, feedURL; };
struct Environment {
    std::string brewPath, portPath;                 // "" = not installed
    std::vector<std::string> appFolders;            // /Applications, ~/Applications
    std::function<std::optional<BundleInfo>(const std::string& appPath)> readBundle;
    std::function<bool(const std::string& path)> exists; // for _MASReceipt/receipt
    std::string country = "us";
};
Environment defaultEnvironment();                    // platform file

struct SourceStatus { Source source; bool available = false; std::string error; };
struct CheckResult { std::vector<OutdatedItem> items; std::vector<SourceStatus> sources; };
CheckResult checkUpdates(const RunFn&, const Environment&, const std::function<bool()>& cancelled);
std::vector<std::string> upgradeCommand(const Environment&, const OutdatedItem&); // argv, exposed for tests
CommandResult upgradeBrew(const RunFn&, const Environment&, const OutdatedItem&);
std::string manualCommand(const OutdatedItem&); // "sudo port upgrade curl", "brew upgrade --cask x"
```

- [ ] **Step 1: Write failing tests** with a fake `RunFn` that records argv and answers by `argv[0]`/`argv[1]`:
  - `testRunCommandCapturesOutput`: `runCommand({"/bin/echo","hi"},5)` → exit 0, output `"hi\n"`. `runCommand({"/nonexistent"},5).exitCode != 0`.
  - `testRunCommandTimesOut`: `/bin/sleep 5`, timeout 1 → `-1`, elapsed < 3 s.
  - `testCheckMissingToolsAreNotErrors`: empty `brewPath`/`portPath`, no apps → sources Homebrew and MacPorts `available=false`, `error==""`; no command run.
  - `testCheckRunsBrewUpdateThenOutdated`: calls in order `brew update`, `brew outdated --json=v2`, `brew info --cask --json=v2 --installed`.
  - `testCheckReportsBrewFailureKeepsOthers`: brew outdated exit 1 → Homebrew `error` non-empty; a Sparkle item from the same run is still in `items`.
  - `testCheckSparkleSkipsCaskAppsAndHttp`: apps `LinearMouse.app` (cask app, https feed, outdated) and `Foo.app` (feed `http://…`) and `Bar.app` (https feed, `bundleVersion "100"`, appcast `150`/`1.5`) → only `Bar` listed with `installedVersion` = its short version, `latestVersion "1.5"`. curl called only for `Bar`.
  - `testCheckSkipsSparkleWithoutBundleVersion`: feed present, `bundleVersion ""` → not listed, curl not called.
  - `testCheckAppStoreBatchesLookup`: two apps with receipts; mdls returns ids `"111"` and `"222"`; exactly one curl call whose URL contains `id=111,222&country=tr` (env country `tr`); lookup says `111` is newer → one item with `storeId "111"`. An mdls output of `(null)` skips that app.
  - `testCheckCancelSkipsRemainingSources`: `cancelled` returns true after the first command → no further commands.
  - `testUpgradeCommand`: formula → `{"/usr/bin/env","HOMEBREW_NO_AUTO_UPDATE=1","NONINTERACTIVE=1",brew,"upgrade","wget"}`; cask adds `"--cask"` before the name. `manualCommand` for a port item → `"sudo port upgrade curl"`.
- [ ] **Step 2: Build; expect compile failure.**
- [ ] **Step 3: Implement.**
  - `runCommand`: `posix_spawn` with file actions (stdin `/dev/null`, stdout+stderr → one pipe); read with `poll` until EOF or deadline; on deadline `kill(pid, SIGTERM)`, wait 2 s, then `SIGKILL`; always `waitpid`. Retry `EINTR`.
  - Check order: Homebrew, MacPorts, App Store, Sparkle; check `cancelled()` before each command. App enumeration: `std::filesystem::directory_iterator` with `increment(ec)` (no range-for — see CLAUDE.md), top-level `*.app` only. mdls: one call with all receipt apps, `-raw -name kMDItemAppStoreAdamID`; output is NUL-separated values. Country: query param from `env.country`.
  - `updater_mac.mm`: `readBundle` via `CFBundleCreate` + `CFBundleGetValueForInfoDictionaryKey` for `CFBundleShortVersionString`, `CFBundleVersion`, `SUFeedURL`; `country` from `[[NSLocale currentLocale] countryCode]` lowercased, else `us`; `exists` via `std::filesystem::exists(ec)`. Fallback file: same with `readBundle` returning `nullopt`.
- [ ] **Step 4: Build and run `ctest`; expect PASS.**
- [ ] **Step 5: Commit** `feat(updater): check all sources and upgrade brew items`.
