File Organizer

File Organizer sorts a folder into Photos, Videos, Music, Documents and Other. Photos go into a content category or a place, then a year and a month.

Use it

  1. Choose a folder and a layout.
  2. Click Preview and check the plan as folders or on the map.
  3. Click Organize. Files move; nothing is overwritten.

"Photos by Place" asks Apple Maps for place names. In offline mode it uses only places it looked up before, and the map is off.
