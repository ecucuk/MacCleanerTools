Safety

MacCleaner is built so that a mistake can be undone.

  • Every tool shows what it will do before it does it.
  • Removals go to the Trash. Permanent deletion is a separate choice for each clean in Storage Cleaner.
  • An allowlist decides what can be removed at all. System folders, other users' files and apps that come with macOS are never removed.
  • MacCleaner never asks for your password and never runs as root.
