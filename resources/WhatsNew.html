MacCleaner 0.1.0

The first release brings eight tools behind one sidebar:

  • Storage Cleaner — clean caches, logs and developer junk.
  • Large Files — find the biggest files, with Quick Look.
  • Photo Cleaner — remove duplicate and blurry photos.
  • File Organizer — sort a folder by type, content or place.
  • Updater — see outdated apps and update Homebrew items.
  • Uninstaller — remove an app with its leftovers.
  • Performance — watch processes and reclaim memory with Optimize.
  • Antivirus — scan for known malware on demand.

Also new: Settings, offline mode, Check for Updates, Help and this window.
